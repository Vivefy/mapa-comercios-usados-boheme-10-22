# Mapa Interactivo Vivefy

Este es un mapa interactivo diseñado para visualizar datos de comercios y locales usados con filtros por distancia, antigüedad, categoría y segmento. 

📍 Proyecto: Análisis comercial Boheme 10/22  
🌐 Desarrollado por: Vivefy  
🎯 Hecho con: Leaflet.js + HTML + JavaScript

## Visualización en línea

👉 Puedes verlo en funcionamiento aquí:  
https://<TU_USUARIO>.github.io/mapa-interactivo-vivefy/

> Reemplaza `<TU_USUARIO>` por tu nombre de usuario de GitHub.

## Archivos

- `index.html`: página principal
- `main.js`: lógica de los filtros y el mapa
- `estilos.css`: estilos visuales
- `data.json`: datos de comercios
- `data_usados.json`: datos de locales usados
- `punto_base.png`: ícono base para el punto central
- `logo_vivefy.png`: logo de la empresa

## Cómo desplegar en GitHub Pages

1. Sube todos los archivos a un repositorio.
2. Ve a **Settings > Pages**
3. En "Branch", selecciona `main` y `/ (root)`
4. Guarda y espera unos segundos.
5. Tu mapa estará disponible en una URL como:  
   `https://<TU_USUARIO>.github.io/mapa-interactivo-vivefy/`
